3 分鐘設定：用 GitHub repo 做資料庫

  1. 開一個 private repo（例如 wine-journal-data），勾「Add a README file」。
  2. Repo 內 Add file → Create new file，檔名 data/tastings.json，內容 {"records":[]}，Commit。
  3. 去 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    • Repository access：Only select repositories → 揀 wine-journal-data
    • Repository permissions → Contents: Read and write
    • Expiration：自己揀（過期要重新產生）
  4. 複製 github_pat_…，返上面填 Token / Owner / Repo / Branch main / Path data/tastings.json。
  5. 按 🔌 測試連線 → 成功後按 💾 儲存並重新連線。之後每儲存一杯酒，app 會自動 commit 一次；換電話／換電腦填同樣設定就即刻見到同一份資料。
安全提示：token 等於你個 repo 嘅鎖匙，只會存喺呢部裝置嘅 localStorage，唔會送第三方。切勿喺公用電腦填。建議 private repo + fine-grained token（只授權一個 repo 嘅 Contents 讀寫）。如果 token 洩漏，去 GitHub 即刻 Revoke 再產生新一個即可。
限制：每次儲存＝1 個 commit（GitHub 免費額度 5,000 requests/小時，絕對夠用）；資料檔建議保持 < 50MB（所以預設唔上傳相片）；Gist 單檔上限約 1MB，只適合純文字。
