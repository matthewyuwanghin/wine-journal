🔐 Token → base64 轉換器

純本地運算（btoa），唔會發送任何資料上網。用完可以刪咗呢個檔。
⚠️ 呢個轉換唔係加密，只係將 github_pat_ 字串變成唔會被 GitHub secret scanning 直接比對到嘅形式。 任何人有心都解得開，所以網站 repo 如果係 public，最安全做法係改用 private repo，或者唔將 token 寫入檔案（每部機喺 ⚙️ 設定自己貼一次）。
  1. 去 GitHub 產生新 token（Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；權限只揀 Contents: Read and write、只揀 wine-journal-data）
  2. 貼入上面個格 → 撳「轉換成 base64」
  3. 用文字編輯器開 index.html，搵 token_b64:，將引號內嗰串換成新結果
  4. 存檔 → 上載去 GitHub（Add file → Upload files → 覆蓋 index.html → Commit changes）
  5. 等 1 分鐘 → 每部裝置強制 refresh → 頂部 pill 變返 GitHub · matthewyuwanghin/wine-journal-data
💡 唔想再 push？都可以：喺 app 的 ⚙️ 設定 → Token 格直接貼新 token → 「💾 儲存並重新連線」。 呢個做法只影響該部裝置（存喺 localStorage），但唔需要改檔案。
